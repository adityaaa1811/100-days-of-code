# Problem 1: Longest Mountain in Array

Problem:
Find the length of the longest mountain.

Approach:
Used Peak Detection.

Steps:
- Identified valid peaks
- Expanded left and right
- Calculated mountain length
- Tracked maximum length

Time Complexity:
O(n)

Space Complexity:
O(1)

Learnings:
- Peak Detection
- Array Traversal
- Expansion Technique

# Problem 2: Number of Good Pairs

Problem:
Count pairs (i, j) where:
nums[i] == nums[j]
and i < j.

Approach:
Used HashMap Frequency Counting.

Steps:
- Stored frequency of each number
- Counted valid pairs
- Updated frequency map

Time Complexity:
O(n)

Space Complexity:
O(n)

Learnings:
- Frequency Counting
- HashMap
- Pair Counting
