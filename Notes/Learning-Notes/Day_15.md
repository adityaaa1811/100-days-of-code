# Problem 1: Contains Duplicate II

Problem:
Given an array and an integer k,
determine whether there are two equal elements
whose indices differ by at most k.

Approach:
Used HashMap to store the latest index
of each element.

While traversing:
- if element already exists in map
- calculate index difference
- if difference <= k return true

Otherwise update the index.

Time Complexity:
O(n)

Space Complexity:
O(n)

Learnings:
- Revised HashMap usage
- Learned index tracking
- Improved array traversal
- Understood distance-based conditions

# Problem 2: Find the Difference

Problem:
Given two strings s and t,
where t is generated by shuffling s
and adding one extra character,
find the extra character.

Approach:
Used XOR operation.

Properties:
- a ^ a = 0
- a ^ 0 = a

XOR all characters from both strings.

Matching characters cancel each other,
leaving only the extra character.

Time Complexity:
O(n)

Space Complexity:
O(1)

Learnings:
- Revised XOR concepts
- Practiced character manipulation
- Solved problem without extra memory
- Understood XOR applications beyond numbers
