# Problem 1: Remove Duplicates from Sorted Array

Approach:
Used two pointers.

One pointer tracked the position
for the next unique element.

Traversed array once and updated
values in-place.

Time Complexity:
O(n)

Space Complexity:
O(1)

Learnings:
- Revised Two Pointer technique
- Learned in-place modification
- Improved array traversal logic

# Problem 2: Missing Number

Problem:
Given an array containing n distinct numbers
from 0 to n, find the missing number.

Approach 1:
Used mathematical formula.

Expected Sum:
n * (n + 1) / 2

Actual Sum:
Sum of array elements

Missing Number:
Expected Sum - Actual Sum

Time Complexity:
O(n)

Space Complexity:
O(1)

Learnings:
- Learned mathematical optimization
- Avoided extra memory usage
- Understood alternative approaches
- Improved problem-solving efficiency
